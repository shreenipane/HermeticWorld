## Part A: `python/hermetic_slice/pkg_index.py`

### A1. `env_info(image: str) -> dict`
Run one container (`--rm --network none --entrypoint /bin/bash`), activate `testbed` (fall back to the image's default `python` if conda is absent), and return:
- `python_version`, e.g. `"3.9"`;
- `implementation_tag`, e.g. `"cp39"`;
- `packages`: `[{"name", "version"}]` from `pip list --format=json`;
- `editable`: the names listed by `pip list --editable --format=json`.

### A2. `wheel_compatible(filename: str, py: str) -> bool`, with `py` like `"3.9"`
Parse the wheel filename (`name-ver(-build)?-pytag-abitag-plattag.whl`; tags may be compound, separated by `.`). It's compatible if:
- **some** python tag is `py3`, `py<major><minor>` or `cp<major><minor>`, or (with abi `abi3`) any `cp3x` where x ≤ minor;
- the abi is `none`, `abi3` or `cp<major><minor>`;
- **some** platform tag is `any`, or starts with `manylinux` and ends with `x86_64`, or is `linux_x86_64`.

Anything that fails to parse is incompatible. Sdists aren't wheels; they're always kept as a fallback.

### A3. `build_index(task: dict, env: dict, http_get, index_dir: Path, *, versions_per_package: int = 5) -> dict`
1. `cutoff = T_world` from `task["cutoffs"]["t_world"]`.
2. Use every package in `env["packages"]`, **excluding the target project**: anything in `env["editable"]`, and the project named after `task["repo"]`'s last path segment, normalized. The target project must never be in the index (channel 4: a post-fix version of the target).
3. For each package, fetch `https://pypi.org/pypi/<name>/json`. A version is **eligible** if it has at least one file with `upload_time ≤ cutoff`. Within an eligible version, keep only files uploaded ≤ cutoff that are compatible wheels or sdists.
   - Serve the newest `versions_per_package` eligible versions. Sort versions by the **earliest upload time** of their kept files, not by string, to avoid writing a PEP 440 parser.
   - **Yanked files** uploaded ≤ cutoff are served anyway, because a yank after the cutoff can't be dated (§6.3). List them in the report.
4. Download each kept file via `http_get`, check its `sha256` against the digest (raise `IndexBuildError` on a mismatch), and store it at `index_dir/files/<filename>`.
5. Write a PEP 503 simple index:
   - `index_dir/simple/index.html` lists the projects;
   - `index_dir/simple/<normalized-name>/index.html` holds `<a href="../../files/<filename>#sha256=<hex>" data-requires-python="<html-escaped>">filename</a>`, adding the `data-requires-python` attribute only when it's set;
   - normalize names per PEP 503 (`re.sub(r"[-_.]+", "-", name).lower()`).
6. Return a report, `index_report` (also written as `index_dir/index-report.json`), with one entry per installed package:
   - `name`, `installed_version`;
   - `installed_version_uploaded`: the earliest upload time of that version's files, or null if not on PyPI;
   - `installed_newer_than_t_world` (bool);
   - `served_versions`, `served_files`, `yanked_served`.

   Plus `excluded`, the target-project names, and totals.

### A4. `class_b_warnings(report) -> list[str]`
Return one line per installed package that's newer than `T_world`, e.g. `"attrs 23.1.0 installed (uploaded 2023-04-16) is newer than T_world 2019-11-14 (repo_only: listed, not rebuilt)"`.

## Part B: `python/hermetic_slice/world.py`

### B1. `start_world(task: dict, image: str, index_dir: Path, *, name: str) -> World`
`World` is a frozen dataclass with `name`, `network`, `index_container` and `agent_container`.
- `docker network create --internal <name>-net`.
- **Index container:** `python:3.12-alpine`, named `<name>-index`, on that network, with `index_dir` mounted **read-only** at `/srv`, running `python -m http.server 8080 --directory /srv`. Wait until it answers, with a timeout.
- **Agent container:** `image`, named `<name>-agent`, on that network only, kept alive with `sleep infinity` (use `--entrypoint /bin/bash` plus `-c "sleep infinity"`). Set these environment variables:
  - `PIP_INDEX_URL=http://<name>-index:8080/simple/`
  - `PIP_TRUSTED_HOST=<name>-index`
  - `PIP_DISABLE_PIP_VERSION_CHECK=1`
- If any step fails, clean up whatever was created.

### B2. `world_exec(world, script: str, *, timeout: int = 600) -> tuple[int, str]`
Run `docker exec <agent> /bin/bash -lc <script>` and return the exit code and the combined output, decoded with replacement. This is the primitive that T0.5 (grader) and T0.6 (agent) will build on.

### B3. `stop_world(world)`
Remove both containers and the network, ignoring "not found". It must be idempotent.

### B4. `probe(world, task, report) -> dict` (a mini §9.6, written as `<task_dir>/world/probe.json` by the CLI)
Inside the agent container, with the `testbed` env activated, check that:
1. **positive:** `pip download --no-deps --dest /tmp/p <pkg>==<v>` succeeds for one served package and version (pick the first);
2. **negative, newer:** for one installed package that's `installed_newer_than_t_world`, `pip download --no-deps <pkg>==<installed_version>` **fails**;
3. **negative, target:** `pip download --no-deps <target project>` **fails**;
4. **egress:** `https://pypi.org/simple/` is unreachable, DNS for `pypi.org` fails, and `http://1.1.1.1/` is unreachable (use `python -c` with `urllib` and a 5 s timeout);
5. **name isolation:** the index container is reachable by name.

Return `{check: {"ok": bool, "detail": str}}` plus `"all_ok"`. A negative check is `ok` when the action **failed**.
