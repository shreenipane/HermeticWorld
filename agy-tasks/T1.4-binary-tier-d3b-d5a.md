## Part A: binary-tier fingerprints (TR-SC-5)

## Part B: module `binary`, D3b

Extract a set of strings from each format, then apply the match rule. Detection is by magic bytes, and the extension is at most a hint.

| Format | Detect | Extract |
|---|---|---|
| ELF | `\x7fELF`, 32 and 64 bit, both endians | Null-terminated strings from `.dynstr`, `.strtab`, and printable runs of 6 or more bytes from `.rodata`, `.data`, `.comment`. Locate sections through the section header table |
| Java `.class` | `CAFEBABE` | UTF-8 entries of the constant pool. Handle every tag's size, including the two slots of Long and Double |
| wasm | `\0asm` | Export and import names, the `name` custom section, and printable runs of 6 or more bytes from the data section |
| Minified JS or CSS bundle | Text with a line of at least 5000 characters, or path ending `.min.js`, `.min.css`, `.bundle.js` | Tokens from `winnow::tokenize` |

`.jar` files are zips, so their `.class` members come through `ContainerScanner` already.

- **Match rule.** A unit matches when it contains at least 60% of a hunk's items, by exact equality against the extracted strings or, for printable runs, as a whole-token substring (the characters around it aren't `[A-Za-z0-9_]`). Use `opts.binary_threshold`, default 0.60.
- **Finding.** Detector `D3b`, channel `binary_elf`, `binary_class`, `binary_wasm` or `binary_minified`, severity `gate`, with the matched items as evidence (at most 5).
- **Wiring.** `ContainerScanner::scan` calls this before the plain-text path. Recognised binaries no longer get the "skipped binary file" `info`, because they've been scanned. Other NUL-containing files keep it. Minified text gets D3b in addition to tiers 1 and 3.
- Add D3b to SARIF.

## Part C: D5a, target project at a post-fix version

- **Task input.** Add `version: Option<String>` with a serde default to `TaskJson` and `TaskInput`. Older `task.json` files must still load.
- **Project name.** From `repo`, take the part after `/`. Compare names after PEP 503 normalisation: lowercase, with runs of `-`, `_` and `.` as a single `-`. Allow one extra `--target-package <name>` CLI argument, repeatable, for projects whose PyPI name differs from the repository name.
- **Scan.** In `scan_tree`, read every `*.dist-info/METADATA` and `*.egg-info/PKG-INFO`, and any file named `PKG-INFO`. Parse the `Name:` and `Version:` headers. Skip non-matching names.
- **Version rule.** Parse the PEP 440 release segment and any `.devN`. With task version `V` (for example `3.0`):
  - a release tuple greater than `V`, comparing only as many components as `V` has, gives a D5a gate, channel `target_version`;
  - a release tuple equal to `V` on those components passes;
  - a `.devN` where N is an 8-digit `YYYYMMDD` or a 14-digit timestamp later than `T_clock`'s date gives a gate, channel `target_dev_date`;
  - an unparseable version gives `info`, channel `target_version_unknown`;
  - if the task has no `version`, emit one `info`, channel `target_version_unknown`, for each copy found.
- Evidence states the path, the found version and the task's version. Add D5a to SARIF.

## Tests (all offline)

Build every fixture in a tempdir at test time.

- **Part A:** an item at the base is subtracted; a short identifier isn't an item; a hunk with one item is skipped.
- **ELF:** hand-build minimal 64-bit LE and 32-bit BE files with a section header table. A symbol in `.strtab` matching the items gives a `binary_elf` gate. A clean ELF gives none.
- **Class:** a hand-built class file with a Long entry before the matching UTF-8 entry, proving the two-slot rule.
- **wasm:** a hand-built module with a matching export name.
- **Minified:** a long-line bundle with the fix's identifiers gives `binary_minified`.
- **Nested:** a `.class` inside a `.jar` inside a `.tar.gz` gives a gate with the right `!/` path.
- **Whole-token rule:** a printable run holding the item only as a substring of a longer identifier doesn't match.
- **Hostile, one test each, none may panic:** ELF section offset past the end; section name index past `.shstrtab`; ELF with 0xFFFF sections declared; class file with a constant-pool count larger than the file; truncated class entry; wasm section length past the end.
