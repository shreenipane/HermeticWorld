## Part A: `python/hermetic_slice/http.py`

- `HttpGet = Callable[[str], bytes]` is the type every fetching function accepts, so tests can inject a fake.
- `make_http_get(cache_dir: Path, *, sleep=time.sleep, token: str | None = None) -> HttpGet` returns a function that:
  - **reads through a disk cache** at `cache_dir/http/<sha256(url)>.body`. A cache hit makes no network call.
  - sends `User-Agent: hermetic-world-intake/0.1`.
  - adds `Authorization: Bearer <token>` **only** for `https://api.github.com/` URLs, and only if a token is given. The CLI reads it from the `GITHUB_TOKEN` environment variable. The token must never appear in the cache, in an exception message or in any output.
  - retries up to 5 attempts, sleeping 2, 4, 8 then 16 s, on HTTP 429, any 5xx, `URLError` or a timeout (`urlopen` with `timeout=60`). Any other 4xx raises `HttpError(url, status)` immediately, with no retry.
  - only caches 200 responses.

## Part B: `python/hermetic_slice/intake.py`

1. **`load_verified(http_get, cache_dir) -> dict[str, dict]`**
   - Page through `/rows` until `num_rows_total` is reached.
   - Reject (raise `IntakeError`) on:
     - any page with `partial: true`;
     - any row with non-empty `truncated_cells`;
     - a duplicate `instance_id` with **different** content;
     - a final unique count ≠ `num_rows_total`.
   - Parse `FAIL_TO_PASS` and `PASS_TO_PASS` with `json.loads`.
   - Cache the result as `cache_dir/swebench_verified.jsonl` (one row per line, sorted by `instance_id`). If that file exists, read it and make no requests.
2. **`linked_refs(repo: str, pr_body: str) -> list[IssueRef]`**
   - `IssueRef` is a frozen dataclass: `kind` (`"github"` or `"trac"`), `number: int`.
   - **GitHub:** a closing keyword (`close|closes|closed|fix|fixes|fixed|resolve|resolves|resolved`, any case, optionally followed by `:`), then whitespace, then either `#N` or `https://github.com/{repo}/issues/N`.
   - **Trac:** only when `repo == "django/django"`: any `https://code.djangoproject.com/ticket/N` in the body.
   - Deduplicate, keeping the first-seen order.
3. **`fetch_issue_created(ref, repo, http_get) -> datetime | None`**: returns `None` (plus a warning) for a GitHub "issue" that is really a PR.
4. **`repo_dates(repo: str, base_commit: str, cache_dir: Path, clone_url: str | None = None) -> tuple[datetime, datetime]`**
   - Returns `(base_commit_time, repo_first_commit_time)`.
   - Clone bare into `cache_dir/repos/{owner}__{name}.git`, or `git fetch` into it if it already exists. Use `--filter=blob:none` **only** when `clone_url` is an `https://` URL: tests pass a local path, and local clones don't support filters without extra config.
   - `base_commit_time` is the base commit's committer date (`%cI`).
   - `repo_first_commit_time` is the **minimum of author and committer dates** over the root commits reachable from the base (`git rev-list --max-parents=0 <base>`). The earliest plausible date gives fewer discards, which gives an earlier `T_world`, which is the safe direction.
5. **`intake_task(instance_id, rows, http_get, cache_dir, out_dir, clone_url=None) -> Path`**
   - Combine the above.
   - Call `compute_cutoffs` with: `issue_created` = the earliest resolved issue date; `pr_opened` = the PR's `created_at`; the fix commits; and the two repo dates.
   - Write this layout:

```
out_dir/<instance_id>/
  task.json                    # metadata + cutoffs; staging-side, see below
  agent/problem_statement.md   # problem_statement ONLY: never hints_text (thread scrub, §4)
  staging/gold.patch           # row["patch"]
  staging/test.patch           # row["test_patch"]
  staging/hints.txt            # row["hints_text"]
```

`task.json` uses `"schema": "hermetic-slice-task/v1"`, sorted keys, 2-space indent and UTC ISO 8601 times. It contains:
- `instance_id`, `repo`, `pr_number`, `base_commit`, `environment_setup_commit`, `version`, `dataset_created_at`;
- `image`: `"swebench/sweb.eval.x86_64." + instance_id.lower().replace("__", "_1776_") + ":latest"` (verified on Docker Hub);
- `sources`: `pr_url`, plus `issue_refs` as a list of `{kind, number, created_at|null}`;
- `dates`: `pr_opened`, `issue_created`, `fix_commits` (list of `{sha, author_date, committer_date}`), `base_commit_time`, `repo_first_commit_time`;
- `cutoffs`: `t_world`, `t_clock`, `discarded`;
- `tests`: `FAIL_TO_PASS`, `PASS_TO_PASS`;
- `warnings`: a list of strings. Add one when no issue reference was found, and add this one for **every** task: `"problem_statement taken as scraped, not at its revision as of T_world (Phase 0 gap, spec section 4)"`.

`task.json` must **not** contain `patch`, `test_patch` or `hints_text`. The `agent/` directory must contain nothing but `problem_statement.md`.
