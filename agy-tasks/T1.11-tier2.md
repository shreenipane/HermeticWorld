## Part A: symbols of the fix (`tier2.rs`)
For each hunk of the gold patch in a `.py` file, parse the base file and the fixed file with tree-sitter. The **modified statements** are the smallest statement nodes (simple statements, or the header line of a compound statement) that overlap a removed line (in the base parse) or an added line (in the fixed parse). From them collect:
- identifiers; attribute chains as the full dotted text and each component; keyword-argument names (`strict` in `f(strict=False)`); string literal contents (without quotes and prefixes, 3+ chars); numeric literals other than 0 and 1.
- Exclude Python keywords and a short stop list (`self`, `cls`, `None`, `True`, `False`, `args`, `kwargs`).
- Record the hunk's **anchors**: the changed file's base name with and without `.py` (`cookies.py`, `cookies`), its module path (`requests.cookies`), and the enclosing function or method name and class name, from the tree-sitter parse.

**IDF.** Document frequency = the number of base-tree `.py` files whose identifier/attribute/literal set (by a fast token scan, no full parse needed: reuse `crate::winnow::tokenize`) contains the symbol; `idf = ln((N + 1) / (df + 1)) + 1`, N = number of `.py` files. Cap the base-tree scan at 20,000 files and 200 MiB; record when capped. A symbol that is absent from the base tree (df = 0) gets the maximum weight. Store per hunk: anchors, `Vec<(symbol, weight)>`, total weight.

## Part B: matching (`Tier2` findings)
For every text unit that `scan` already matches (problem statement for D0, every text unit for D2), tokenize it the same way, plus extract backtick- and quote-delimited spans as candidate symbols. A hunk matches the unit when:
- at least one **anchor** appears in the unit (case-sensitive, as a whole token), and
- the summed weight of the hunk's symbols that appear in the unit is ≥ `tier2_threshold` × the hunk's total weight, where `tier2_threshold` is a new `ScanOptions` field, default **0.35** (to be calibrated in E3; document that), **and** at least 2 distinct symbols appear.
- Output: detector `D0` (problem statement) or `D2` (other units), channel `tier2`, severity **Review**, confidence = the weight fraction rounded to 2 places, hunk index, evidence = the matched anchor plus up to 5 matched symbols. One finding per (unit, hunk).
- A unit that already has a tier-1 or tier-3 Gate finding for the same hunk gets no tier-2 finding (avoid noise).

Wire it through `MatchSink::text` and `scan_problem_statement`. Tier 2 is **not** answered from the index: add `"T2"` to the query's `not_covered` list (and document why: symbol tokens are not stored).
