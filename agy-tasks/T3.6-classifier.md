## What to build
New package `python/hermetic_classifier/` (`__init__.py`, `baseline.py`, `__main__.py`) and tests in `python/tests/test_classifier.py`.

1. **Patch normalisation.** Parse unified diffs (the agent's final patch and the gold patch) into per-file lists of added and removed lines; bounded input size, bounded line length and file count; malformed diffs give a typed error, never an unhandled exception. Normalise lines: strip trailing whitespace, collapse runs of spaces and tabs, drop blank lines and pure comment lines for Python (`#`), keep everything else exactly.
2. **Baseline label (the SWE-bench exact-match baseline).** `classify(agent_patch, gold_patch) -> Result` with: `exact_match` (normalised added and removed lines identical per file, ignoring hunk positions and file order), `added_line_overlap` (share of the gold patch's normalised added lines, of at least a minimum length, that occur in the agent's added lines; an integer per-mille, no floats), `label` (`retrieved` when exact match, or when overlap is at or above a named threshold and the gold patch has at least a named minimum number of qualifying lines; else `derived`), `confidence` (integer per-mille from a documented fixed table), and `evidence` (sorted list of file, agent line number, gold line number for matching lines, bounded count).
3. **Status rule (TR-CLS-2).** `run_status_hint(label, world_sealed: bool, gate_says_leak: bool) -> "review" | None`: a retrieved label in a sealed world gives `review`; a disagreement between the gate and the classifier gives `review`; otherwise None. Table-driven test over all eight combinations.
4. **Audit record payload.** A function that builds the `hermetic-transcript-audit/v1` predicate as a plain dict: run digest (validated `sha256:` + 64 hex), label, confidence, evidence spans; deterministic JSON output (sorted keys, no floats, no timestamps, no host values). Known-answer test.
5. **CLI.** `python -m hermetic_classifier --agent-patch FILE --gold-patch FILE --run-digest DIGEST [--sealed] [--gate-leak]` prints the predicate JSON and the status hint; exit 0, or 1 on error. Files are opened without following symlinks and must be regular files under a size cap.

Tests: exact match with reordered files and shifted hunks; whitespace-only and comment-only differences still match; a one-token change does not match; overlap threshold boundaries; tiny gold patches never give `retrieved` by overlap alone; hostile diffs (oversized, binary, NUL bytes, no headers, 100000 hunks) raise the typed error; determinism known answer; CLI errors.
